设备与波形 · Coyote Game Hub

手机 App 扫码、电脑蓝牙、通道设置和波形编辑保留在这里。切换到本页会暂停战局控制，避免两套强度设置互相覆盖。设置完成后点击上方“恢复监听”。

蓝牙直连需使用支持 Web Bluetooth 的浏览器（如 Chrome / Edge）；浏览器配对权限由你操作。切换页签不会卸载设备页面，蓝牙连接会保持。

直播显示与悬浮窗

查看此页不会暂停战局，也不会改变强度。原版 OBS 显示和皮肤完整保留，原有浏览器源链接无需重建。

联动状态条 · 无需会话 ID

显示本程序已发送的指令和暂停/离线状态。它不是物理设备实测值；需要设备反馈时请选择左侧原版显示。

建议浏览器源：440 × 180；背景透明。

支持 Document Picture-in-Picture 的浏览器可置顶；其他浏览器打开普通小窗。OBS 浏览器源是在直播画面里叠加，不等于游戏内悬浮窗。

第一次接入 OBS：只需这几步
  1. 在 OBS 的“来源”中点＋，选择“浏览器”，关闭“本地文件”。
  2. 粘贴上面的 URL，填写建议宽高；不要把控制台首页当作显示源。
  3. 将该来源放在游戏画面上方，拖动到需要的位置。OBS 默认透明背景可保留。
  4. OBS 与本程序在同一台电脑时使用当前地址。源显示离线时，先确认程序仍在运行，再刷新浏览器源。

旧版的高级皮肤参数仍在“设备与波形 → 添加到OBS”。直播中仅查看显示时用本页，避免进入设备设置模式暂停战局。

开始使用 · 游戏与连接

第一次使用？按这个顺序来
  1. 选游戏目录，点“使用此目录”；游戏关闭时安装采集插件。
  2. 进入“设备与波形”，扫码或用蓝牙连接，并在 Hub 中启用输出。
  3. 回到战局页，点击“恢复监听”，再进入训练场。这里的“Hub 可达”只代表服务在线。
  4. 需要直播显示时打开“直播 / 悬浮窗”，复制浏览器源链接。调参数前可先去实验室预览。

自动查找已安装的游戏，也可以选择文件夹或直接粘贴路径。选到 bin64 或主程序时，会自动定位到安装根目录。

监听与强度

伤害合并窗口不延迟首击；同一窗口后续受击会更新累计伤害，基础增量只加一次。

事件规则

临时波形结束后恢复仍有效的状态波形，再恢复默认波形。优先级：临时事件 → 进水 → 起火 → 默认。启用事件波形需先设置默认波形。

伤害曲线与衰减

factor 是每一步保留比例：0.4 表示剩余 40%。基础强度、状态附加值、曲线和随机值相加后，统一限制在最大强度内。

基础值恢复与高级响应

游戏采集间隔需要保存后重新安装插件、重启游戏才能生效。其他规则参数保存后即时生效。

设备服务与目标

改变设备目标会先向旧目标请求归零，然后暂停新目标。保存后检查连接，再点恢复监听。B 通道设置和设备强度上限在“设备与波形”页面。

波形库

波形列表尚未读取

可选 App 导出的 .pulse 文本、波形二维码图片或 Hub 的 JSON / JSON5 波形库。图片和 .pulse 以文件名命名。 这里导入的是公共波形，不会自动播放；相同项自动跳过，同 ID 内容不同会提示并取消整批导入。只想给一台设备添加时，使用“设备与波形”里的导入按钮。

参数方案

导出当前配置

导入只填入表单，可以先预览；点击保存后才会应用。导出包含本地游戏路径及设备目标，不包含配对凭据。

完整配置（含设备目标、连杀门槛、波形 ID 列表）

此编辑器单独保存；设备地址和目标也可在上方表单修改；网页端口需退出后修改 config.yaml。规则 pulseId 支持 ID 数组，每次事件随机选一个；默认波形支持 Hub 播放列表。
